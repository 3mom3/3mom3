## 👋 About Me

I explore **AI agents, automated research, and reliable evaluation**, turning practical research problems into reusable tools and workflows.

## 🔭 Current Focus

- **Research Agents:** Building workflows for literature search, idea discovery, evidence verification, and automated review.
- **Workflow Reliability:** Improving tool use, source tracking, stage-level checks, and failure handling to make agent workflows easier to inspect and reproduce.
- **AI Evaluation:** Understanding whether model outputs are supported by evidence and whether evaluation results reflect real capabilities.

## 🛠️ Open Source

### [ARIS — Auto-Research-In-Sleep](https://github.com/wanshuiyin/Auto-claude-code-research-in-sleep)

I contribute to open-source agent workflows for automated research, with a focus on:

- **Multi-source Debugging Search:** Developing the `web-debug-search` skill with source and language routing, error matching, and version tracking to gather relevant debugging evidence.
- **Stage-level Evidence Checks:** Adding checks across five stages of `idea-discovery` to verify execution status, artifacts, and report content, and record why a stage is blocked.
- **Integration & Testing:** Keeping research search options and documentation consistent, and adding tests for OpenAlex retrieval.
